# after://cp

**Bridging the gap between competitive programming and real-world software engineering.**

## What is this?

`aftercp.com` is a project hub and (eventually) a storytelling-driven guidance site for competitive programmers making the jump into real-world software engineering.

CP teaches you how to solve problems fast. It doesn't tell you what "System Design," "DevOps," or "clean architecture" actually mean, why they exist, or where to even start. Most guidance treats these topics as blackboxes you're just supposed to "go learn."

This site exists to open those blackboxes — with context, history, and curiosity, not just checklists.

## Current state

This is the **landing page** — a teaser for what's coming, plus a hub for live projects. The full guidance library (domain-by-domain roadmaps, told as stories) is planned for later.

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
